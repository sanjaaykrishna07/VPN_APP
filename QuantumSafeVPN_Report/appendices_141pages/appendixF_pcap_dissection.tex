\section{Useful Wireshark Display Filters}
To isolate QuantumSafe VPN traffic in Wireshark:
\begin{itemize}
    \item Isolate all VPN transport traffic: \texttt{tcp.port == 7000}
    \item Filter TCP Handshake: \texttt{tcp.port == 7000 and tcp.flags.syn == 1}
    \item Inspect Handshake Payloads: \texttt{tcp.port == 7000 and tcp.len > 1000}
    \item Verify TUN Packets on Gateway: \texttt{ip.addr == 10.8.0.2}
\end{itemize}
