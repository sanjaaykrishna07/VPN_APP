\reportabstract{
\hspace*{1.25cm}In an era characterized by rapid advancements in quantum computing, conventional public-key cryptosystems face catastrophic vulnerability to Shor's algorithm. Concurrently, hostile intelligence doctrines actively execute ``Harvest Now, Decrypt Later'' (HNDL) attacks, intercepting and archiving high-value mobile network traffic today for retrospective decryption once cryptographically relevant quantum computers (CRQCs) emerge. Virtual Private Networks (VPNs) deployed on Android endpoints represent the frontline defense perimeter for secure communication, yet legacy mobile solutions rely almost exclusively on vulnerable classical key exchange protocols. This project presents QuantumSafe VPN, a comprehensive engineering initiative bridging theoretical lattice cryptography and production-grade mobile networking. Architected natively on Android's \texttt{VpnService} subsystem with a modern declarative Jetpack Compose interface, the system implements finalized NIST Post-Quantum Cryptography standards: Module-Lattice Key Encapsulation (ML-KEM-1024, NIST FIPS 203) for quantum-resistant session key agreement and Module-Lattice Digital Signatures (ML-DSA-65, NIST FIPS 204) for mutual authentication and server certificate pinning. Line-rate packet transport is encapsulated in AES-256-GCM (FIPS 197) authenticated encryption, driven by RFC~5869 HKDF-SHA256 session key expansion, an optimized pure-Kotlin Keccak-$f[1600]$ engine, and a 64-bit monotonic anti-replay sliding-window counter. Rigorous empirical validation over physical Wi-Fi and LTE testbeds demonstrates full post-quantum tunnel establishment in 18.42\,ms, 94.6\,Mbps sustained throughput over 100\,Mbps links with a negligible 2.18\,ms latency delta, and a lean 13.4\,MB APK footprint, establishing a robust open-source benchmark for mobile post-quantum privacy.

\noindent\textbf{Keywords:} Post-Quantum Cryptography; Android VpnService; ML-KEM-1024; ML-DSA-65; AES-256-GCM; Harvest Now Decrypt Later; Mobile Network Security; Jetpack Compose; Network Tunneling; Minimal White UI.
}
