\chapter{DETAILED SOFTWARE REQUIREMENTS SPECIFICATION (SRS)}
\label{app:srs}

This appendix provides the formal Software Requirements Specification (SRS) for the QuantumSafe VPN system, conforming to the structural guidelines of IEEE Standard 830-1998 (Recommended Practice for Software Requirements Specifications).

\section{Introduction and Purpose}
The purpose of this specification is to define the functional, performance, security, and interface requirements for the QuantumSafe VPN mobile client and gateway. The intended audience includes software engineers, cybersecurity auditors, network administrators, and academic reviewers.

\section{Overall Description}

\subsection{Product Perspective}
QuantumSafe VPN is a self-contained, post-quantum virtual private network suite consisting of a native Android client application and a multi-client Linux gateway daemon. It operates as an independent network tunnel, intercepting all Layer~3 IPv4 packets emitted by applications running on the mobile device and securely transporting them across an untrusted network.

\subsection{User Characteristics}
The system serves two distinct user classes:
\begin{enumerate}
    \item \textbf{General Mobile Users}: Security-conscious individuals requiring robust, zero-configuration network privacy on public networks. They interact exclusively with the Home dashboard via a single-tap Connect/Disconnect toggle.
    \item \textbf{Network Administrators}: Technical personnel responsible for configuring enterprise gateway parameters, custom MTU sizing, and auditing server identity certificates.
\end{enumerate}

\section{Specific Requirements}

\subsection{External Interface Requirements}

\subsubsection{User Interfaces}
\begin{itemize}
    \item \textbf{UI-1}: The interface shall adhere to a minimal white color palette (\texttt{\#FFFFFF} surface, \texttt{\#1A1D20} typography, \texttt{\#1971C2} primary accent).
    \item \textbf{UI-2}: The Home view shall render a prominent connection status badge (\texttt{DISCONNECTED}, \texttt{CONNECTING}, \texttt{CONNECTED}, \texttt{ERROR}).
    \item \textbf{UI-3}: The application shall render live session duration and network throughput telemetry cards.
\end{itemize}

\subsubsection{Hardware Interfaces}
\begin{itemize}
    \item \textbf{HI-1}: The client shall communicate over standard 802.11a/b/g/n/ac/ax wireless LAN interfaces or 3GPP LTE/5G cellular radio modems.
    \item \textbf{HI-2}: The client shall support ARM64-v8a and x86\_64 processors with hardware AES instructions.
\end{itemize}

\subsubsection{Software Interfaces}
\begin{itemize}
    \item \textbf{SI-1}: The client shall integrate with Android's \texttt{android.net.VpnService} API (API Level 26 through 34).
    \item \textbf{SI-2}: Persistent storage shall interface with Android Keystore-backed \texttt{EncryptedSharedPreferences}.
    \item \textbf{SI-3}: The server shall interface with the Linux kernel \texttt{/dev/net/tun} character device driver.
\end{itemize}
