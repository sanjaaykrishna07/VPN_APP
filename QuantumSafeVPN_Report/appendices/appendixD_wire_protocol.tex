\chapter{WIRE PROTOCOL SPECIFICATION AND CONFIGURATION SCHEMAS}
\label{app:wire_protocol}

This appendix provides the formal byte-level protocol specification governing all network communications between the QuantumSafe VPN Android client and the Linux gateway.

\section{Transport Layer Characteristics}
\begin{itemize}
    \item Underlying Transport: Transmission Control Protocol (TCP).
    \item Default Listener Port: 7000 (configurable via server environment variable \texttt{VPN\_}\allowbreak\texttt{SERVER\_}\allowbreak\texttt{PORT}).
    \item Byte Ordering: Big-Endian (Network Byte Order, RFC 1700).
    \item Stream Framing Mechanism: 4-byte unsigned 32-bit length prefix preceding every protocol data unit.
\end{itemize}

\section{Handshake Transcript and Serialization}

\subsection{Stage 3 Authentication Transcript}
The server's ML-DSA-65 digital signature is evaluated over the contiguous byte concatenation of the protocol version string, the client's ML-KEM-1024 public key, and the server's ciphertext:
\begin{equation}
\text{Transcript} = \texttt{b"QuantumSafeVPN-v1"} \parallel pk_{\text{client}} \parallel c
\end{equation}
\begin{itemize}
    \item Length of Protocol Header: 17 Bytes.
    \item Length of $pk_{\text{client}}$: 1,568 Bytes.
    \item Length of Ciphertext $c$: 1,568 Bytes.
    \item Total Transcript Size Signed: Exactly 3,153 Bytes.
\end{itemize}
