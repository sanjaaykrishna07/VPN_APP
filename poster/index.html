Project Overview
A snapshot of the what, why, and how

QuantumSafe VPN is an end-to-end post-quantum cryptographic VPN engineered to protect mobile IP communications against Harvest Now, Decrypt Later (HNDL) attacks and future cryptanalytically relevant quantum computers running Shor's algorithm.

By superseding vulnerable RSA and elliptic curve Diffie-Hellman primitives with finalized NIST standards (FIPS 203 ML-KEM-1024 & FIPS 204 ML-DSA-65), the system delivers authenticated, hardware-accelerated AES-256-GCM encrypted tunneling between an unprivileged Android client and a hardened Linux security gateway with automated dynamic IP pooling.

Impact & Conclusion
highlights the value and quantum-resilient defense outcome

QuantumSafe VPN establishes a breakthrough mobile implementation of post-quantum cryptography, proving that lattice-based security standards (FIPS 203 & 204) can be deployed on resource-constrained Android smartphones without compromising throughput, battery endurance, or user experience.

By resolving critical platform challenges—such as socket routing loops, Low Memory Killer (LMK) eviction, and Keccak CPU bottlenecks—this project delivers a practical blueprint for mobile zero-trust enterprise security, safeguarding vital data against state-sponsored quantum decryption.

Insights & Results
what the platform verifies, defends, and delivers

Testing on a physical Google Pixel (Android 14) connected to a Kali Linux gateway verified end-to-end mathematical correctness across all NIST Known-Answer Test (KAT) vectors with a 100% automated test suite pass rate.

Adversary simulation confirmed absolute cryptographic integrity: 100% of ciphertext bit-flipping attacks were instantly dropped by Galois MAC tags, packet replays were thwarted by sliding-window sequence tracking, and rogue server substitutions were blocked via ML-DSA fingerprint pinning.
